代理池

有序代理列表，自上而下故障转移。仅订阅流量只服务 OpenAI/Anthropic 订阅端点（OAuth 登录、令牌刷新、订阅对话）；全局流量服务所有不绕过代理的出站请求。代理地址里写的账号密码会自动拆进「凭证保管库」，不会明文落盘；带凭证的代理仅限订阅作用域。留空列表则回落到环境变量（http_proxy / https_proxy）。修改立即生效，无需重启。

ℹ️
不代理域名

在此添加不需要走代理的域名后缀或主机名（每行一个，后缀匹配）。匹配的请求会完全绕过 HTTP 代理。

💡 提示：内网地址和 LLM API 域名都应加在这里。企业/VPN 代理会静默断开长连接（SSE 流），导致 BrokenPipeError，添加对应域名即可解决。也可通过环境变量 PROXY_BYPASS_DOMAINS（逗号分隔）配置，两处合并生效。
